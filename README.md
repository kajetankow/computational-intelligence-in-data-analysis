# computational-intelligence-in-data-analysis# Computational Intelligence in Data Analysis

This repository contains selected academic projects developed as part of the **Computational Intelligence in Data Analysis** course.  
Each project is placed in a separate directory and includes its own description, notebook, report, figures, and additional source files when needed.

## Projects

### Parcel Locker TSP Optimization

Route optimization for parcel locker logistics using OpenStreetMap road-network data.  
The project compares Genetic Algorithm and Ant Colony Optimization for solving a realistic asymmetric TSP problem.

### Fuzzy CPU Cooling Control

Fuzzy logic-based CPU cooling controller using temperature and noise feedback.  
The project includes both Python-based simulation and a physical Arduino implementation.

### Monte Carlo Pi Estimation and PRNG Comparison

Monte Carlo estimation of π with a comparison of different pseudorandom number generators.  
The project analyzes convergence, absolute error, variance, and execution time.
